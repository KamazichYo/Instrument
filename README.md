# Instrument
Инструменты для монтажа — веб-приложение (PWA), которое ставится на экран «Домой» iPhone.
Вся обработка идёт прямо в телефоне: файлы никуда не загружаются, работает офлайн.

**Открыть:** https://kamazichyo.github.io/Instrument/

## Установка на iPhone
1. Открыть ссылку в **Safari**.
2. Кнопка «Поделиться» → **«На экран „Домой“»**.
3. Иконка Instrument появится среди приложений и откроется на весь экран.

## Инструменты
| Плитка | Что делает |
|---|---|
| **Звук** | ИИ-очистка голоса (DeepFilterNet3), вырезка пауз, тембр, ровность, громкость −14 LUFS |
| **Субтитры** | Распознавание русской речи (Whisper) → вшивание субтитров в видео (для CapCut / Edits на телефоне), а также .srt / .vtt / текст |
| Видео | скоро |

Всё считается на телефоне. Нейросети скачиваются один раз и хранятся в кэше браузера:
DeepFilterNet3 — 34 МБ (лежит в репозитории, `assets/vendor/deepfilternet`),
Whisper base — ~80 МБ, Whisper small — ~250 МБ (с Hugging Face, `onnx-community/whisper-*_timestamped`).

### Звук
Всё переключателями. Выбираете запись → нажимаете варианты → «С обработкой» сразу проигрывает
12-секундный фрагмент, «Оригинал» — исходник (громкость выровнена для честного сравнения).

| Группа | Варианты |
|---|---|
| ИИ-очистка | Выкл · Мягко · Средне · Максимум (когда включена — «Шум» и «Эхо» не нужны и скрыты) |
| Паузы | Не резать · Мягко · Обычно · Плотно |
| Эхо комнаты / Шум (без ИИ) | Выкл · Слабо · Средне · Сильно |
| Голос | Как есть · Чётче · Теплее · Ярко |
| Ровность | Выкл · Слегка · Сильно |
| Громкость | Соцсети (−14) · Подкаст (−16) · Не менять |

Замеры на русской речи с эхом и шумом (хвосты эха / шум в паузах относительно речи):
исходник 30 / 30 дБ → обычная обработка «Сильно» 47 / 46 дБ → ИИ 55 / 51 дБ.
Задержка нейросети (30 мс) компенсируется — звук не разъезжается с видео.

### Субтитры
Видео, звук или кнопка «Взять звук из „Звука“» (тайминг совпадёт с порезанными паузами).
Распознавание: «Быстро» (Whisper base) или «Точно» (Whisper small — заметно лучше для русского).
Стиль: Классика (2 строки) · Shorts (3–4 слова) · По слову. Текст: как есть · без точек · ЗАГЛАВНЫЕ.
Фразы можно исправить и удалить, тап по времени проигрывает кусок, текущая фраза видна поверх видео.
**Вшивание в видео** (CapCut и Edits на телефоне не умеют импортировать .srt): вид — обводка,
акцент текущего слова (жёлтым) или плашка; место — низ (над кнопками Reels/Shorts), центр, верх;
три размера. Предпросмотр рисуется поверх видео тем же кодом, что и вшивание (`assets/subs/render.js`).
Кадры декодируются и кодируются через WebCodecs ([Mediabunny](https://mediabunny.dev/), MPL-2.0),
звук копируется без перекодирования, поворот iPhone «запекается», видео больше Full HD уменьшается до 1920.
Сценарий: смонтировать ролик в CapCut / Edits → сохранить → «Субтитры» → «Вшить» → «Сохранить видео» → Фото.
Известные «галлюцинации» Whisper на тишине («Субтитры сделал DimaTorzok» и т.п.) вычищаются.
Страница работает в режиме cross-origin isolation (заголовки добавляет `sw.js`) — распознавание
идёт в несколько потоков, примерно в 1.5 раза быстрее.

### Цепочка обработки звука
моно → [ИИ: DeepFilterNet3] → срез низов 80 Гц → [без ИИ: шумодав Wiener + подавление
поздней реверберации] → поиск пауз → [без ИИ: экспандер хвостов] → тембр → де-эссер → компрессор
→ склейка с микрофейдами → нормализация BS.1770 → лимитер −1.5 дБ. Результат — WAV 48 кГц / 16 бит.

## Структура
```
index.html              главный экран с плитками
audio/index.html        страница «Звук»
assets/app.css          общий стиль
subtitles/index.html    страница «Субтитры»
assets/audio/dsp.js     обработка звука (чистый JS, тестируется в Node)
assets/audio/ai.js      ИИ-очистка (DeepFilterNet3)
assets/audio/worker.js  обработка в фоновом потоке
assets/audio/app.js     интерфейс «Звука»
assets/subs/cues.js     слова → субтитры, SRT/VTT
assets/subs/asr-worker.js  распознавание речи (Whisper, transformers.js)
assets/subs/render.js   отрисовка субтитра на кадре (предпросмотр и вшивание)
assets/subs/burn.js     вшивание субтитров в видео (Mediabunny / WebCodecs)
assets/subs/app.js      интерфейс «Субтитров»
assets/shared/handoff.js   передача файла между инструментами (IndexedDB)
assets/vendor/          сторонние библиотеки с лицензиями
sw.js, manifest.webmanifest, icons/   PWA
tests/                  тесты: npm test
```
Новый инструмент = папка со своей `index.html` + плитка в `index.html` + файлы в `sw.js`.
