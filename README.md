# Instrument
Инструменты для монтажа — веб-приложение (PWA), которое ставится на экран «Домой» iPhone.
Вся обработка идёт прямо в телефоне: файлы никуда не загружаются, работает офлайн.

**Открыть:** https://kamazichyo.github.io/Instrument/

## Установка на iPhone
1. Открыть ссылку в **Safari**.
2. Кнопка «Поделиться» → **«На экран „Домой“»**.
3. Иконка Instrument появится среди приложений и откроется на весь экран.

## Инструменты
| Плитка | Что делает |
|---|---|
| **Звук** | Вырезка пауз, подавление эха комнаты, шумодав, тембр голоса, ровность, громкость −14 LUFS |
| Видео | скоро |
| Субтитры | скоро |

### Звук: как пользоваться
Всё переключателями, без ползунков. Выбираете запись → нажимаете варианты → кнопка
«С обработкой» сразу проигрывает 12-секундный фрагмент с выбранными вариантами, «Оригинал» — исходник
(громкость выровнена для честного сравнения). Нравится — «Обработать весь файл».

| Группа | Варианты |
|---|---|
| Паузы | Не резать · Мягко · Обычно · Плотно |
| Эхо комнаты | Выкл · Слабо · Средне · Сильно |
| Шум | Выкл · Слабо · Средне · Сильно |
| Голос | Как есть · Чётче · Теплее · Ярко |
| Ровность | Выкл · Слегка · Сильно |
| Громкость | Соцсети (−14) · Подкаст (−16) · Не менять |

Пресет по умолчанию — «Комната с голыми стенами».

### Цепочка обработки
моно → срез низов 80 Гц (24 дБ/окт) → один проход STFT: шумодав (Wiener, профиль шума из пауз)
\+ подавление поздней реверберации (модель Лебарта, спектральное вычитание хвоста)
→ поиск пауз → экспандер (дожим хвостов эха между словами) → тембр → де-эссер → компрессор
→ склейка с микрофейдами → нормализация по BS.1770 → лимитер −1.5 дБ.
Результат — WAV 48 кГц / 16 бит, моно.

## Структура
```
index.html              главный экран с плитками
audio/index.html        страница «Звук»
assets/app.css          общий стиль
assets/audio/dsp.js     обработка звука (чистый JS, тестируется в Node)
assets/audio/worker.js  обработка в фоновом потоке
assets/audio/app.js     интерфейс
sw.js, manifest.webmanifest, icons/   PWA
tests/                  тесты: npm test
```
Новый инструмент = папка со своей `index.html` + плитка в `index.html` + файлы в `sw.js`.
