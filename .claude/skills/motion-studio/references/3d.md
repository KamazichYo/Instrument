# 3D-моушн

3D даёт то, чего нет в плоской графике: объём, свет, отражения, параллакс, «дорогую» камеру. Здесь собрано то, что делает 3D-ролик премиальным, а не «демкой three.js». Источники: лучшие 3D-скиллы (3dviz-pro-max, Threejs-Awesome-Graphics, iart webgl-animation) и практика продуктовых рендеров (Apple, Spline, Cinema 4D / Octane).

## Стек в Motion Studio
`lib/three/three.mg.js` — three.js r187 одним файлом (MIT): GLTFLoader, RoundedBox, TextGeometry, RoomEnvironment, постобработка (Bloom, Bokeh, Output, Shader), SVGLoader, SimplexNoise.
`lib/three/mg3d.js` — **MG3**, обвязка для видео: сцена, свет, материалы, текст, частицы, отражения, рендер каждого кадра.
Шаблоны: `3d-hero` (герой-объект или ваша GLB), `3d-title` (объёмный заголовок с кириллицей), `3d-cards` (пролёт камеры сквозь карточки).

```js
const comp = MG.comp({ format: '16:9', fps: 30, duration: 6 });
const tl = comp.tl();
comp.setup(async () => {
  const S = MG3.stage(comp, { look: 'studio', floor: { y: -1, shadow: 0.4 }, orbit: { yaw: -25, pitch: 8, radius: 9 } });
  const cube = new S.THREE.Mesh(MG3.roundedBox(2, 2, 2, 0.3), MG3.mat.glossy('#ff5a1f'));
  cube.castShadow = true; S.add(cube);
  tl.from(cube, { y: 5, rotY: -180, scale: 0.5 }, { at: 0.2, dur: 1, ease: 'land' });   // таймлайн MG двигает 3D
  tl.to(S.orbit, { yaw: 25 }, { at: 0, dur: 6, ease: 'glide' });                         // облёт камеры
});
```

## Детерминизм (главное отличие от «интерактивных» 3D-скиллов)
- Всё — функция `t`. Никаких `clock.getDelta()`, `+=` в кадре, `mixer.update(dt)`, `setAnimationLoop`.
- Анимации GLB: `S.onFrame(MG3.clips(gltf))` вызывает `mixer.setTime(t)`.
- Свои движения: `S.onFrame(t => { obj.position.y = base + Math.sin(t) * 0.1 })`. Шейдеры — через uniform `uTime` (`S.timed(material)`).
- Случайность — `MG.rng(seed)`. `lint.mjs` проверяет повторную перемотку и ловит `+=`.

## Что умеет таймлайн с 3D
`tl.to(mesh, { x, y, z, rotX, rotY, rotZ (градусы), scale, scaleX/Y/Z })`, любые вложенные свойства: `'material.opacity'`, `'material.emissiveIntensity'`, `'material.color': '#ff0'`, `'uniforms.uMix.value'`. Цели: `S.camera.position`, `S.target` (куда смотрит камера), `S.orbit` ({yaw, pitch, radius}), `S.key.position` / `S.rim.position` (свет), `S.bloom.strength`, `S.camera` + `'fov'`.

## Свет — 80% качества
- **Три точки**: ключ (сверху-сбоку, с тенью) · контровой (сзади, отделяет силуэт, часто цветной) · заполнение (небо/полусфера, слабое). В MG3: `S.key`, `S.rim`, `S.fill`.
- **Окружение (env)** даёт отражения. Хрому и глянцу нужны контрастные отражения: в MG3 по умолчанию «студия с софтбоксами» (тёмная комната, светящиеся полосы). Для светлых сцен — `envMap: 'room'`.
- **Двигай свет, а не только объект**: проезд ключевого/контрового света даёт бегущий блик по поверхности — самый дешёвый «вау» (см. `3d-title`).
- **Образы** (`look`): `studio` (тёмный, тёплый контр), `bright` (светлый Apple-стиль), `neon` (фиолет + розовый контр, сильный bloom), `sunset`, `noir` (ч/б, жёсткий ключ).
- Тени мягкие (`PCFSoft`) и обязательно есть: объект без тени «висит» в пустоте. Пол-тень: `floor: { shadow: 0.4 }`; глянцевый чёрный пол с отражением: `MG3.reflect(S, group)`.

## Материалы (`MG3.mat`)
| Материал | Когда |
|---|---|
| `glossy(c)` | пластик/иконки/игрушки, клиркоут, «дорого» |
| `matte(c)`, `clay()` | спокойный, «скульптурный» вид, макеты |
| `metal(c)`, `chrome()`, `gold()` | премиум, титры, награды — нужен контрастный env |
| `glass(tint)`, `frosted(tint)` | стекло/лёд: преломление (transmission), за ним должно быть что-то видно |
| `emissive(c, k)` | неон, экраны, свечение + bloom |
| `iridescent(c)` | перламутр, «тех»-эстетика |
Правило: 1 главный материал + 1 акцент + нейтральный. Шероховатость 0.15–0.35 выглядит дороже идеального зеркала 0.

## Камера
- **Фокусное**: `fov` 24–35 (≈50–85 мм) — продуктовый «теле», без искажений. 45–60 — широкий, драматичный пролёт.
- **Движения**: облёт (orbit) · наезд (dolly) · проезд (truck) · кран (pedestal) · пролёт сквозь (fly-through). Одно основное движение на сцену + медленный дрейф всё время.
- Камера тянется к действию: `tl.to(S.target, …)` переводит взгляд, `tl.to(S.orbit, { radius })` — наезд.
- Кривые камеры: `glide` / `[0.45,0,0.15,1]` (разгон и долгое торможение). Камера никогда не стоит мёртво.
- Вертикаль 9:16: MG3 сам отодвигает камеру (`×1.55`), но перепроверь кадр — объект должен занимать 60–80% ширины.

## Композиция и движение в 3D
- **Падение/прилёт с вращением** + сжатие при приземлении (scaleY 0.86 на 2–3 кадра, пружина назад) — физика веса.
- **Спутники** (2–3 мелких объекта других материалов) дают глубину и параллакс; группируй с героем, если герой сдвигается.
- **Стаггер по буквам** 3D-текста: от центра к краям, из глубины (z −14) с вращением по X — шаблон `3d-title`.
- **Частицы/пыль** (`MG3.particles`) — воздух и масштаб; немного, полупрозрачно.
- **Глубина**: туман (`fog: [near, far]`), DOF (BokehPass, дорого), передний план, проходящий близко к камере.
- **DOM поверх 3D**: заголовки и плашки — обычным HTML (чётче и дешевле, чем 3D-текст); 3D-текст — только для героя-надписи. Привязать подпись к объекту: `MG3.toScreen(S, obj.position)`.

## Свои 3D-модели
- **Meshy** (в аккаунте может быть скилл `meshy-3d-agent:meshy-3d-generation`): текст или картинка → GLB с текстурами, риг и анимация. Положи GLB в `videos/<имя>/assets/`, `P.model = 'assets/model.glb'` в `3d-hero`.
- **Spline** (spline.design) → Export → GLTF/GLB. **Blender** → File → Export → glTF 2.0 (.glb), «Apply Modifiers», анимации — NLA/Actions. Для тяжёлого моделирования есть Blender MCP (`ahujasid/mcp-for-blender`, 33k★).
- **Sketchfab / Poly Haven** (CC0/CC-BY) — проверь лицензию и укажи автора в NOTE.md.
- `node engine/embed.mjs assets/model.glb` → `assets/model.glb.js` (подключить `<script>`): проект открывается двойным кликом. Большие модели сожми: `npx @gltf-transform/cli optimize in.glb out.glb` (без Draco — его декодер не встроен; используй meshopt/quantize).
- `MG3.normalize(obj, size)` — центр в 0 и нужный размер; `MG3.clips(gltf)` — встроенные анимации.
- Свой шрифт для 3D-текста: `node engine/font3d.mjs Brand.ttf -o assets/brand.font.js --name brand` → `MG3.text3d('Текст', { font: 'brand' })`.

## Производительность рендера
WebGL в headless-Chromium: на ноутбуке с GPU — быстро; на сервере без GPU (SwiftShader) ≈0.5–1 с/кадр в 1080p с bloom. Черновик: `--scale 0.5`; тени 2048 → 1024 если долго; меньше сегментов геометрии; bloom/Bokeh выключать на черновике. Потоки `--workers` помогают и для 3D.

## Чего не делать
- Объект без тени и без контрового света («наклейка на чёрном»).
- Чистый RoomEnvironment на хроме (серый «пластик») — нужен контрастный env.
- Вращение героя по кругу весь ролик — это заставка, а не моушн. Движение должно что-то говорить: прилёт → посадка → раскрытие → уступает место тексту.
- Bloom на всём подряд, белые пересветы. Порог bloom 0.85–0.93.
- Пять материалов и пять цветов в одной сцене.
- Мелкий текст на 3D-карточках, который зритель не успеет прочитать на пролёте.
