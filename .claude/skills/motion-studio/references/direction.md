# Режиссура: от запроса к раскадровке

## 1. Одна правда (4 строки)
- **Проблема**: что болит у зрителя.
- **Аудитория и площадка**: кто смотрит и где (лента со звуком выкл? YouTube-интро?).
- **Цель**: что зритель сделает/запомнит после.
- **Эмоция**: одно слово (уверенность, восторг, спокойствие, «вау, быстро»).
Плюс **один реальный момент**, ради которого ролик: фича, цифра, результат. Предположения назови явно.

## 2. Найди идею (минимум три, разных типов)
Типы: документалка одной задачи в UI · одна длинная «сквозная» камера · шутка с персонажем/объектом · типографское эссе под голос · монтаж реальных результатов · тишина, которая ломается · трансформация (самая заезженная — бери последней).
Тесты: **закрой логотип** — ролик всё ещё работает только для этого бренда? **Подставь конкурента** — если подходит, идея слабая. Выбери одну и объясни одной строкой.

## 3. Форма ролика
- **Соцсети 6–15 с**: хук (0–2 с, ≤5 слов, движение с первого кадра) → суть/доказательство → призыв или «вау»-финал.
- **Лаунч 20–45 с**: хук → проблема (короткая) → продукт делает дело (большая часть!) → доказательство → логотип + призыв (≤25% длины).
- **Эксплейнер 30–90 с**: вопрос → 3 шага/факта, каждый — свой визуальный объект → вывод. Голос ведёт, графика показывает (не дублирует слова текстом).
- **Перебивки к говорящей голове**: 3–10 с на идею, минимум 2 с лица между вставками, не перекрывать первую секунду хука и эмоциональные/личные фразы.

## 4. Таблица битов (STORYBOARD.md)
| # | Время | Покупает (зритель понимает…) | В кадре / что двигается | Вход → выход (чем стыкуется) | Звук |
|---|---|---|---|---|---|
| 1 | 0.0–1.4 | «это про скорость монтажа» | «Монтаж» влетает с ×2.4, блюр→0 | рез на движении вверх → бит 2 входит снизу | swish |
Правила: каждый бит **покупает одно убеждение** (иначе вырезать); у каждого — «картинка с закрытым текстом» (что видно без слов); роль: хук / поворот / доказательство / призыв.

## 5. Анти-«нейрослоп» — удалить, не оправдывать
1. Служебный «HUD»: название в углу, счётчики «01 / 04», таймкоды, рамки-уголки, прогресс-бары, надписи капсом с разрядкой.
2. Вёрстка презентации: заголовок слева + картинка справа, кикер над заголовком, «шапка-тело-подвал».
3. Генерик-UI: карточка со статус-точкой и «$value», «Good morning», серые скелетоны, выдуманные имена и цифры.
4. Первая ассоциация с названием (ракета для «launch», звёзды для «star»).
5. Выдуманная статистика, стена цифр, дисклеймеры на экране.
6. Слоганы: «Не просто X. Это Y.», «Откройте для себя», «будущее уже здесь», три слова-предложения подряд.
7. Хаус-стиль по умолчанию: гигантское обрезанное слово, заливка-круг между сценами, точка, превращающаяся в логотип.
8. Маленькая карточка в пустоте; плоский цветной фон на каждую сцену.
9. Футер-концовка: лого + слоган + кнопка + URL дольше 1.4 с.
10. Сдача без просмотра своего рендера.

## 6. Честный просмотр
- Опиши каждый кадр листа одной фразой: что в кадре, кто герой, похоже ли на слайд.
- Тест миниатюры: стоп-кадр в середине — понятно, о чём ролик?
- Тест скорости: посмотри на 1× — успеваешь прочитать? (стоп-кадры обманывают).
- Кадры в середине перехода: нет ли белой вспышки, дёрганья, наложения текста на текст.
- Исправляй в порядке: неправда → идея → стыки → иерархия → тайминг → отделка → звук.
- Когда есть варианты — дай пользователю выбрать 2 версии, его реакцию запиши в `videos/TASTE.md` и учитывай в следующих роликах.
