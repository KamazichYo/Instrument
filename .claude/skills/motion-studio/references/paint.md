# Масляная живопись (PAINT)

`lib/paint.js` даёт ролику вид картины маслом. Мазки кистью со щетинками рисуются сразу в два холста: цвет и высоту краски. Финальный WebGL-проход освещает рельеф: на гребнях мазков блики, во впадинах тени, сквозь тонкую краску видно переплетение холста, сверху тёплый лак и виньетка. Полный пример — `videos/brooklyn-alive` (город с двумя версиями: дождливой и солнечной).

## API
```js
const pen = PAINT.surface(w, h);                 // {c, h, cx, hx} — холст цвета и рельефа
PAINT.stroke(pen, x, y, angDeg, len, width, col, { r, bend, var, hue, thick, alpha, taper, nb });
PAINT.path(pen, [[x,y],...], width, col, { even: true });   // длинный мазок: рука, провод, перила
PAINT.dab(pen, x, y, size, col, o);              // короткий мазок: лист, цветок, блик
PAINT.blob(pen, x, y, radius, col, { sy });      // круглое: фрукт, капля, клякса (рельеф-купол)
PAINT.rect / ellipse / poly(pen, ..., col, { ang, angJ, len, sw, dens, var, hue, thick, underCol, flow, clip, under })
//   col может быть функцией (u, v, x, y) → цвет: градиенты, свет, пятна. underCol — подмалёвок.
PAINT.text(pen, 'PIZZA', x, y, '700 30px Unbounded', col, { thick });   // буквы густой краской
const s = PAINT.sprite(w, h, ox, oy, k, (pen) => {...});  PAINT.put(pen, s, x, y, rot, sx, sy, alpha);
const imp = PAINT.impasto(canvas, W, H, { relief: 1.6, spec: 0.12, weave: 0.3, vignette: 0.3 });
imp.render(colorCanvas, heightCanvas);           // в onSeek, последним
```

## Как строить сцену
1. **Статичное рисуй один раз** в `comp.setup` (async, с `await` между крупными частями, чтобы рендер не считал страницу зависшей): небо, дальний план, дома. Это большие холсты; в кадре их ставят `drawImage` с камерой. Рисование 1080p-улицы занимает ~30 с, кадр — ~1 с.
2. **Подвижное рисуй мазками в каждом кадре.** Чтобы мазки не «кипели», у каждого объекта свой `r: PAINT.rng(seed)`, и порядок вызовов не меняется от кадра к кадру. Двигающееся рисуй со своим rng: без него сид берётся из координат и меняется каждый кадр.
3. **Тени и свет** рисуй пером без рельефа: `{cx: pen.cx, hx: null}`. Тени полупрозрачными мазками, свечение через `PAINT.glow(cx, ...)`.
4. **Кадр:** заливка рельефа серым 128 → слои → объекты → `imp.render`.

## Как выглядит масло, а не «фильтр»
- Ломаный цвет: соседние мазки отличаются по тону (`var` 0.06–0.12) и чуть по оттенку (`hue` 0.02–0.04). В серых сценах `hue` ≈ 0, иначе пойдёт цветная рябь.
- Направление мазка следует форме: кирпич — горизонтально, доски и шторы — вертикально, небо — длинными волнами, вокруг солнца — по кругу (`flow`).
- Размер: крупные плоскости — `len` 40–110, `sw` 15–35. Мелкие мазки по всей картине дают шум, а не живопись.
- Подмалёвок (`underCol`) темнее или теплее основного тона. Он должен проглядывать редко (`dens` 1.3–1.6).
- Рельеф умеренный: `relief` 1.5–2.5. Выше картинка становится резьбой по камню или тиснением.
- Свет по логике: солнце с одной стороны, тени от карнизов, подоконников и людей падают в противоположную, в тени холоднее, на свету теплее.

## Физика без накопления
Всё рассчитывается формулами от `t`: затухающие колебания от ударов (`exp(-k·d)·sin(2πf·d)`), прыжки с потерей энергии, падение листа (снос + синус), пружина-переход 0→1, ветер на шуме. Никаких `+=` между кадрами (`lint.mjs` проверит).
