# Плейбуки по жанрам

## kinetic — кинетическая типографика
Шаблон `kinetic-type`. Текст = герой. Время слов — из речи (`words.mjs`) или из сетки (`beats.mjs`, смена фразы на сильную долю).
- 1 фраза = 1 бит, 1–4 слова. Размеры: hero / big / mid / small — контраст минимум ×2 между соседями.
- Одно слово-акцент на фразу (`*слово*` цветом, `_слово_` с подчёркиванием), не больше.
- Варианты механики (меняй в шаблоне): маска снизу (`MG.mask` + `yp:110`), поворот по букве (`rotate:-12` stagger 0.03), растяжение `scaleY:2 → 1`, слово «выбивает» предыдущее (выход вверх на `leave` в момент входа нового).
- Фон живёт: свет по шуму + зерно. Для бренда — его цвет как свет, а не заливка.

## promo — промо/лаунч продукта
Шаблон `product-promo` (+ хук из `kinetic-type`). Главное — продукт **делает дело на экране**.
- Сними реальный интерфейс: скриншоты/HTML сайта через Playwright, или пересобери UI в HTML по скриншоту (реальные тексты и цвета!).
- Сцена = одно действие: клик → результат. Курсор входит крупным, паркуется, жмёт (сжатие 2–3 кадра), цель отвечает через кадр.
- Камера тянется к действию: наезд на поле ввода, на результат. Масштаб так, чтобы элемент занял 60–90% ширины.
- Финал: логотип из ×2.6 с блюром, призыв одной строкой, ≤1.4 с удержания.

## broll — перебивки и оверлеи для говорящей головы
1. Исходник: `ffprobe` (размер, fps, поворот). Субтитры: `.srt` (из Instrument → «Субтитры» или Whisper) → `words.mjs`.
2. План (таблица): # · вход–выход · фраза · что показываем, на каких словах · полный кадр / панель / ничего · почему. Плотность: лёгкая 2–4/мин, средняя 4–7/мин.
3. Каждый клип — отдельная композиция ТОГО ЖЕ размера и fps, что исходник. Смены состояний — на слова: локальное время = время слова − вход клипа.
4. Полноэкранная вставка → `.mp4`. Панель поверх лица/в пустом месте → `--alpha` `.mov`.
5. `composite.mjs plan.json` → `preview.mp4` для согласования. В финале пользователь кладёт клипы в свою монтажку (имена файлов с таймкодом входа: `03-stat_0m32s40.mov`).
Чего нельзя: перекрывать первую секунду хука, личные/эмоциональные фразы; ставить вставки чаще чем через 2 с лица; выдумывать цифры.

## data — графики и цифры
Шаблон `stat-chart`. Только данные пользователя; пример помечай подписью «пример данных».
- Сначала вопрос (что сравниваем), потом рост столбцов с каскадом, значения считаются вместе со столбцом, потом приглушить всё кроме главного, потом герой-цифра.
- Линии: SVG path + `stroke-dasharray`/`stroke-dashoffset` через `--draw` переменную или `tl.call`. Круговые — `conic-gradient` с CSS-переменной.
- Ось и подписи — тихие (серые), значение — громкое.

## logo — стинг логотипа
Шаблон `logo-sting`. 2.5–4 с. Знак собирается из частей своей же формы (не из «точки»), надпись выезжает из маски, блик один раз, удар (impact) в момент «щелчка».
Свой логотип: SVG в `assets/`, части знака — отдельные `<path>`/группы, каждой своя траектория. Для аутро — сделай вариант, который заканчивается на чистом знаке без ухода.

## lower — плашки и титры
Шаблон `lower-third`, рендер `--alpha -o out/name.mov` (ProRes 4444 — CapCut/Premiere/Resolve/Final Cut понимают). Длительность входа 0.6–0.9 с, удержание 3–5 с, выход 0.4–0.5 с.

## captions — субтитры
Шаблон `captions`. `node $S/engine/words.mjs speech.srt --embed videos/x/index.html`. Режимы: `karaoke` (группа 2–4 слова, текущее цветом), `word` (по слову крупно — для динамичных шортсов), `box` (плашка под словом). Позиция `bottom` уже над кнопками Reels. Длительность композиции подстраивается под слова.
Результат: `.mov --alpha` для монтажки или поверх видео: `composite.mjs` с `{"file":"out/captions.mov","in":0,"x":0,"y":0}`.

## explainer — эксплейнер 30–90 с
Одна композиция, сцены — функции `scene1(at)`, `scene2(at)`… каждая добавляет твины в общий `tl` со своим смещением. Голос: пользователь даёт запись (или пишет текст — тогда предложи записать голос в телефоне и прогнать через Instrument → «Звук»). Тайминг сцен — из `words.mjs`.
Один визуальный объект на факт; объект предыдущей сцены превращается в следующий (стык). Текст на экране — не повтор голоса, а ключевое слово/цифра.

## loop — лупы и GIF
Длительность = целое число циклов всех движений (`sin(2πt/D)`). Проверка шва: кадр 0 и кадр D−1/fps должны почти совпасть. Рендер `.gif --scale 0.5` (палитра строится автоматически) или `.mp4` для соцсетей.

## beat — монтаж в бит / музыкальные ролики
`beats.mjs track.mp3` → смены сцен на `downbeats`, акценты (вспышка, рывок камеры, смена цвета) на `onsets`. Раз в 2–4 такта — крупное событие, иначе утомляет. Не ставь событие на каждый бит.

## 3d — 3D-объекты, объёмный текст, пролёты
Читай `references/3d.md`. Шаблоны: `3d-hero` (прилёт героя → посадка → облёт → уступает место заголовку), `3d-title` (буквы из глубины, блик бежит по хрому, отражение в полу), `3d-cards` (пролёт сквозь витрину карточек → разворот главной).
Своя модель: Meshy/Spline/Blender → GLB → `assets/` → `embed.mjs` → `P.model`. Один герой, 2–3 спутника, свет движется, камера никогда не стоит.
