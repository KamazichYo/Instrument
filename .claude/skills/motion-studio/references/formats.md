# Форматы и экспорт

| Площадка | Формат | Размер | Длина | Заметки |
|---|---|---|---|---|
| Reels / TikTok / Shorts | 9:16 | 1080×1920 | 6–60 с (Shorts ≤ 3 мин) | безопасная зона: верх 12%, низ 20%, право 13%; со звуком |
| Лента Instagram / LinkedIn | 4:5 или 1:1 | 1080×1350 / 1080×1080 | 6–30 с | многие смотрят без звука — смысл без голоса |
| YouTube | 16:9 | 1920×1080 (или 4k 3840×2160) | любое | интро ≤ 5 с; title-safe 5–7% по краям |
| X / Telegram | 16:9 или 1:1 | 1920×1080 / 1080×1080 | до 2:20 | — |
| Оверлей для монтажки | как исходник | как исходник | — | `--alpha` → `.mov` ProRes 4444 |
| Веб-баннер, сайт | любой | — | луп | `.webm --alpha` или `.mp4`, `.gif --scale 0.5` для превью |

Переформатирование: тот же `index.html` с `--format 9:16|16:9|1:1|4:5`. Вёрстка в `--u` (1% меньшей стороны) и `.safe` подстраивается; добавь правила `.mg-portrait ...` для вертикали (пример — `product-promo`).

## Что выдаёт render.mjs
- `.mp4` — H.264 High, yuv420p, bt709, limited range, `+faststart`, CRF 16 (соцсети перекодируют — запас качества нужен). Это то, что без проблем загружается в Instagram/TikTok/YouTube.
- `.mov --alpha` — ProRes 4444 с альфой (10 бит). Тяжёлый, но понятный любой монтажке.
- `.webm --alpha` — VP9 с альфой: веб, лёгкий.
- `.gif` — палитра по кадрам, ≤25 fps.
- `--stills` — PNG для проверки и обложек (обложка Reels: кадр с крупным текстом в центре 1:1 области).

## fps
30 — по умолчанию для соцсетей. 25 — если исходник PAL. 60 — для UI-демо с быстрыми движениями (рендер вдвое дольше). Для перебивок — **fps исходника**: `fps: 30000/1001` в `MG.comp` или `--fps 30000/1001` при рендере.

## Скорость рендера
≈4–8 кадров/с на 4 ядрах при 1080p (зависит от блюров и теней). Черновик: `--scale 0.5`. Потоки: `--workers N` (по умолчанию половина ядер). Моушн-блюр `--blur 4` — вчетверо дольше, только для финала.
