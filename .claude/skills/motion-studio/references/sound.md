# Звук

Звук — половина впечатления от моушна. Ролик без звука в Reels выглядит недоделанным.

## Музыка
- **Своя музыка пользователя** (лучше всего): `beats.mjs track.mp3` → `bpm`, `beats`, `downbeats` (сильные доли, эвристика — проверь на слух), `onsets` (акценты). Резы на сильные доли, крупные события раз в 2–4 такта.
- **Сгенерировать**: `music.mjs -o assets/music.wav --dur <длина> --style <pulse|hype|ambient|minimal> --bpm N` — точная сетка в `.beats.json`, финальный удар на последнем такте (`final_hit`) — подгони к нему появление логотипа. Это черновая подложка: честно скажи пользователю и предложи заменить на трек из библиотеки (YouTube Audio Library, Epidemic, Artlist, бесплатные CC0 — Pixabay Music).
- **Подбор темпа**: спокойный/премиум 80–100, продукт/тех 110–128, хайп/спорт 135–150.

## Эффекты (sfx.mjs — синтез, без лицензий)
| Событие | Звук | Громкость (gain в mix) |
|---|---|---|
| смена сцены, пролёт | whoosh (пик сам встаёт на метку) | −8…−4 |
| появление слова/карточки | swish, pop | −12…−8 |
| клик, нажатие | click, tap | −10…−6 |
| печать | type (на каждое 2–3-е нажатие) | −16…−12 |
| счётчик | tick | −16 |
| удар, логотип, кульминация | impact, hit, thump | −4…0 |
| нарастание перед ударом | riser (пик на метку) | −10 |
| успех, «готово» | ding, sparkle | −10…−6 |
| глитч-переход | glitch | −10 |
Правило: **1–3 героических удара на ролик** + тихие взаимодействия. Эффект на каждое движение = шум. Перед главным ударом — 0.2–0.4 с тишины (музыку можно приглушить).

Вариации: `node sfx.mjs whoosh --seed 3 --pitch 0.8 --dur 1.0 -o assets/whoosh-low.wav` — разные seed звучат по-разному, чтобы не было «одного и того же свиша».

## Голос
- Запись пользователя → почистить в Instrument → «Звук» (ИИ-очистка, паузы, −14 LUFS) → `.srt` из «Субтитров» → `words.mjs`.
- Текст за кадром: ~2.5–3 слова/с, одна короткая строка на бит. Текст на экране появляется за 0–2 кадра до того, как слово прозвучит.
- Нет голоса — картинка идёт по сетке музыки.

## Сведение (mix.mjs)
```bash
node $S/engine/mix.mjs --duration 12 --music assets/music.wav --music-gain -6 \
  --vo assets/vo.wav@0.4 --sfx out/video.mp4.events.json --mux out/video.mp4 -o out/final.mp4
```
- Метки `comp.mark(t,'name')` из композиции → `out/<файл>.events.json` → `--sfx`. Свой список: `[{"t":1.2,"sfx":"whoosh","gain":-6},{"t":3,"sfx":"assets/hit.wav"}]`.
- Голос автоматически приглушает музыку (sidechain). `--no-duck` — выключить.
- Итог: −14 LUFS, true peak ≤ −1.5 dBFS (норма Instagram/TikTok/YouTube). `qa.mjs` проверит.
